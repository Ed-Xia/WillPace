🚀 KinetiX API 接口测试工具

用于测试步态分析服务器的 HTTP API 接口

📖 使用说明

  • 步骤 1: 上传跑步视频文件
  • 步骤 2: 使用返回的 videoId 进行视频分析
  • 步骤 3: 等待分析完成后获取报告
  • 步骤 4: 查看报告数据和高级分析结果

POST /api/upload/video

上传跑步视频文件

POST /api/analyze/video

分析已上传的视频

GET /api/report/{id}

获取分析报告详情

GET /api/reports

获取所有报告列表

DELETE /api/report/{id}

删除指定报告

PUT /api/report/{id}/name

更新报告名称
